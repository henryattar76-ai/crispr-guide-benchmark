What this shows

A simple model that only looks at which nucleotide sits at each position of the 30-nt context ranks guides on genes it never trained on with Spearman ≈ 0.38. GC content alone is essentially uninformative here (-0.05). Any published deep model has to clearly beat the position baseline to justify its complexity, and that comparison is what the full benchmark will make.

Scope: this is one dataset and two baselines. No published tool (Rule Set 2, DeepSpCas9, DeepHF, CRISPRon) has been scored yet, so nothing here ranks tools.

Decisions still open

  • Duplicate guides: 931 repeated contexts (same guide in several drug screens) were collapsed by averaging raw scores. This choice must be justified in the methods.
  • In-sample predictions: the Rule Set 2 predictions bundled with this file were trained on the same data, so they cannot be reported as unseen performance.
  • Missing datasets: Kim 2019 (DeepSpCas9), Wang 2019 (DeepHF) and Xiang 2021 (CRISPRon) training data are not yet in hand, so the cross-dataset seen/unseen comparison has not been run on real data.
